The idea

GPMS is the system where the investment portfolio is managed and booked. Each period it delivers its data as a set of files: accounting extracts, master data about each security, exchange rates. Bloomberg data and a few reference lists kept in Excel come with them.

All of these are described in one metadata workbook, 01_Metadata_Import_Source_Files.xlsx. Its control sheet lists every import, and each line carries a table group. The lines of the GPMS group are marked GPMS.

In one line: run the import with the table group GPMS, and every GPMS file of that period is read, checked against its template and turned into a table, ready for the enrichment steps.

Two choices start a run

Reporting date

Which period to import. The date is filled into the file names, so the run finds this period's files, for example the extracts of 30 September 2026.

Table group

Which lines of the control sheet to run. With GPMS, only the 29 GPMS lines are imported; lines of other groups are left alone.

1

Select the GPMS lines

From the control sheet List_Of_Tables, keep the lines whose table group is GPMS.

2

Find each file

Fill the reporting date into the file name and look in the GPMS folder of the period. Most names end in *, so the end of the name may vary.

3

Read it with its template

Read the file as CSV (separator ;), pipe-separated text or Excel, and use the matching schema sheet to give each column its name and type, with the date format on the line.

4

Hand over to enrichment

The typed tables are passed on, each under its table name, to the enrichment steps that follow.

Watch a GPMS import

This follows one real line of the GPMS group, the Local GAAP transaction prices, from the two run choices to a table ready for enrichment. It plays by itself when it comes into view.

The table, file pattern, date format and columns are real entries from the workbook. The period folder and the date written as 20260930 are examples.

What the GPMS group contains

29 lines with 620 columns in total, in four families.

20GPMS accounting extracts

Ten kinds of extract, each once for the Local GAAP books and once for IFRS 9: account movements, holding periods, transaction prices, new trades, repos, closed repos, cash movements, stock transfer reasons, intragroup fields and first-issue internal ratings.

CSV files
2GPMS master data

GPMS_SIGNALETIQUE: the description of every security, with 206 columns. GPMS_RATES: exchange rates per currency and provider.

CSV files with decimal commas
3Bloomberg data

Security data from Bloomberg for the reporting date and the day after (ISIN, country of risk, coupon, maturity, issuer …), plus a list of manual exceptions.

Pipe-separated files and Excel
4Reference lists

Account class types, the not-linked-to-EL list, opening positions and an HBIM database export.

Excel files

The Local GAAP and IFRS 9 version of each extract have exactly the same columns, and so do the two Bloomberg day files.

How a GPMS run works

import_sources(source_group, meta_source, run_parameters) is called with source_group = "GPMS".

1

Read and filter the control sheet

Reads List_Of_Tables from the metadata workbook in the ref layer and keeps the rows with TABLE_GROUP == "GPMS".

2

Fill the path

TABLE_SOURCE_PATH.format(**run_parameters) replaces every {name} with the run parameter of the same name.

3

Find the file

find_matching_file(folder, name) resolves the *. If no file is found, the row is reported as "File does not exist" and skipped; the other rows continue.

4

Read it

Depending on IMPORT_FILE_IMPORT_METHOD, the file goes to import_structured_csv, import_structured_xlsx or the named function.

5

Return the tables

Each result is stored under its TABLE_NAME in a dictionary of DataFrames, which is returned to the enrichment steps.

list_of_sources = list_of_sources.filter(F.col("TABLE_GROUP") == source_group).collect()

for src in list_of_sources:
    src_file = src["TABLE_SOURCE_PATH"].format(**run_parameters)
    src_file = find_matching_file(src_file_directory, src_file_name)
    ...
    dicts[src["TABLE_NAME"]] = imported_src

return dicts        # {"ACCOUNT_LGAAP": df, "TRANSACTION_PRICE_LOCAL": df, …}

PIPE2import_structured_csv, separator |
EXCEL5import_structured_xlsx, sheet from IMPORT_FILE_EXCEL_SHEETBy name: only columns present in both file and schema are kept, missing ones become null, names are upper-cased. Blank rows are removed. If the Excel connector fails, the file is read with pandas, with a case-insensitive sheet lookup.

TAB (separator tab) and FUNCTION are also supported by import_sources; the GPMS group does not use them.

Adding a GPMS file

  • Add a row to List_Of_Tables with TABLE_GROUP = GPMS and a unique TABLE_NAME
  • Set IMPORT_FILE_IMPORT_METHOD: CSV, PIPE, TAB or EXCEL (with IMPORT_FILE_EXCEL_SHEET)
  • Write TABLE_SOURCE_PATH with run-parameter placeholders in braces and * where the name varies
  • For text files, fill SOURCE_DATE_FORMAT and, if needed, SOURCE_DATETIME_FORMAT
  • Add a schema sheet named exactly like the table, with Column_Name and Column_Type; for text files, list the columns in file order
