Comparison Report Viewer

Open the JSON written by save_results() or save_report_to_json() to see row counts, columns, schema and value differences per dataset, without rerunning the notebook. Nothing is uploaded: files are read in your browser.

Or drop files here. Open the part-00000… file Spark wrote; several files at once also work.

Getting the file out of Synapse

  1. Save the results in the notebook. For all datasets of a run: summary, detail, reports = run_comparisons(spark, datasets) then save_results(spark, summary, detail, path). For one dataset: comparator.save_report_to_json(path).
  2. In Synapse Studio, open Data → Linked, browse to that path and download the part-00000… file inside the folder Spark wrote.
  3. Open that file here. The single report also lists which columns have a different data type; the save_results file only says whether the schema matches.
